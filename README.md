# MendiBideak
Euskal Herriko Mendi eta Bidezidorrak.

## **1. IKERKETA:**
**WikiLoc** da nire ustez merkatu hemendik kompetentziarik gogorrena. Nik, pertsonalki ez dut erabiltzen horrelako aplikaziorik, *baina gogoratzen dut udako egun batean bizikleta - irteera bat egin nuen nire anaiarekin eta lagun batekin nun **Outdooractive: Senderismo** deituriko aplikazio bat erabili genuen.* Eta hirugarren bat gehitzeko, bueno, ez dakit kontatzen baldin badu, baina esango nuke **Google Maps** ere honetarako balio duela, eta noski, pertsona pilla - pilla bat ezagutzen dute aplikazio hau.

Nik pentsaten dut 16 urte gorako duten pertsonek erabili izango dutela aplikazio hau, nagusiki mendizaleak diren pertsonek, edo ibiltzea gustoko duten pertsonek edo irteeraren bat egitea nahi duten jendea.



> **ℹ️ Beheko zati hau irakurri nahi ez badezu jun hurrengo atalera. ⚠️**
*Badakit inork galdetu egin didala! Baina nik gustoko dut ibiltzea.*
*Txikitatik ikastolara juten nintzen oinezien edo patinetez (1,8 kilometro), eta noski, etxera ere juten nintzen bidegorritik.*
*Ikastolaz aldatu nindutenean eta baita ere erdi mailan nengoenean etxera juten nintzen oinez (7,6 kilometro).*
*Nire lehenengo urtean Miguel Altuna LHII -n autobuses edo kotxez etorri eta jun egiten nuen, Bergaratik Eskoriatzara 16,6 kilometro daudelako eta ikasteko denborarik ez nukeen izango bestela. Ala ere, 3 edo 4 egunetan bai jun izan nintzen oinez nire etxeraino eta egun batean patinetearekin (manuala; elektrikoa ez dena) erabili izan dut etxeraino juteko.*
*Aurten goiz guztietan Aretxabaletaraino juten naz oinexien (3 kilometro) gero kotxez juteko Miguel Altuna LHII raino, eta etxera juteko ere Aretxabaletatik Eskoriatzaraino juten naz oinezien.*

## **2. ATALA:**

### **WikiLoc**
![WikiLoc](https://viendoosdesdearriba.wordpress.com/wp-content/uploads/2018/10/wikiloc2.png?w=256)
[WikiLoc](https://eu.wikiloc.com/)

Lehen ikusi dudan web orria **WikiLoc** izan da.
🧠 Emendik idei batzuk hartu ditut eta baliteke erabiltzea nire web orrian.
💡 *Adibidez:* Ibilbide bakoitza `div` baten barruan sartzea.
- Distantzia, Desnibel -a eta zailtasuna sartzea argi eta garbi.
  - Hemen klima ere agertzea pentsatu dut.
- Zailtasuna 3 kolore desberdinetan bisualki lagungarria izateko.
- Argazki batzuk ipini.
- Deskripzioren bat.
  - Eta hortaz gain, pentsatu dut Google Maps -en ibilbidearen `esteka` ipini `botoi` baten barruan.
